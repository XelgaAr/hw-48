# Campus — учебный план на Material UI

Адаптивное личное пространство для учебных курсов: создание и редактирование планов, отслеживание уроков, избранное и светлая/тёмная тема.

Домашнее задание: `hw-48-r11.pdf`. Базовая лекция: `#11. React and Bootstrap, Tailwind CSS, Material UI, Ant Design.pdf`.

## Возможности

Каталог учебных целей, форма добавления и редактирования, отметка следующего пройденного урока, избранное, поиск, фильтры и сортировка. Удаление с подтверждением и кратковременной возможностью восстановления. Сводная статистика рассчитывается по реальным значениям; тема, курсы и прогресс сохраняются в localStorage.

На широком экране — постоянная боковая панель, на узком — выдвижное меню. Карточки перестраиваются в одну, две или три колонки. Это планировщик обучения, не площадка с видеоуроками: кнопка «Следующий урок» отмечает один урок как пройденный.

**Стек:** React 19, Vite 8, Material UI 9, Emotion 11, @mui/icons-material.

## Запуск в VS Code

Установите Node.js **24** (рекомендуется; минимальная версия проекта — 22.12) и откройте папку этого репозитория через File → Open Folder. Либо из терминала в общей папке архива:

```bash
cd hw-48-material-ui
code .
npm install
npm run dev -- --open
```

Откроется `http://127.0.0.1:5173/`. `code .` — необязательная команда: при отсутствии VS Code в PATH папку можно открыть вручную. Команды npm выполняются во встроенном Terminal → New Terminal, **из папки с package.json**. Сервер останавливается Ctrl+C.

Зависимости уже перечислены в package.json; повторно выполнять `npm create vite` и устанавливать каждую библиотеку отдельно не нужно. Файл `.nvmrc` содержит `24`; при установленном совместимом менеджере версий можно использовать `nvm install` / `nvm use`. Менеджер версий не обязателен.

Первое подключение к npm создаст `package-lock.json`. Его следует включить в репозиторий. Затем используйте `npm ci` для повторяемой установки. В архив не включены node_modules и dist.

```bash

```

Production preview: `http://127.0.0.1:4173/`. Команда `npm run check` последовательно запускает ESLint, все unit-тесты и сборку. `npm run test:core` не требует установки библиотек приложения; `npm test` может требовать зависимости, указанные в этом проекте.

## Выбор библиотеки и архитектура

Выбрана **Material UI** — одна из трёх альтернатив PDF. Bootstrap, Tailwind и Ant Design не устанавливаются: задание не требует одновременного использования нескольких библиотек.

| Компонент | Использование Material UI |
|---|---|
| `Header.jsx` | AppBar, Toolbar, IconButton, Tooltip |
| `Sidebar.jsx` | Drawer, List, ListItemButton, Chip, LinearProgress, useMediaQuery |
| `StudyStats.jsx` | Paper, Box, Typography |
| `CourseFilters.jsx` | TextField, MenuItem, InputAdornment |
| `CourseCard.jsx` | Card, CardContent, Chip, LinearProgress, Button, Tooltip |
| `CourseForm.jsx` | Dialog, TextField, MenuItem, DialogActions |
| `DeleteDialog.jsx` | Dialog, DialogContentText, Button |
| `App.jsx` | ThemeProvider, CssBaseline, Snackbar, Alert, адаптивная Box-сетка |

`src/theme.js` содержит общую тему через `createTheme`: палитры light/dark, типографику, скругления и overrides. Для HTML-настроек `TextField` используется актуальный `slotProps.htmlInput`; для адаптивной сетки — `Box` с responsive `sx`. Нет зависимости от устаревших props старых версий Grid/TextField.

Состояние курсов принадлежит `App`, а презентационные компоненты получают необходимые данные и callbacks через props. Черновик формы локален для `CourseForm`. `src/domain/courses.js` содержит чистые функции; `src/hooks/usePersistentState.js` отделяет хранение от UI.

### Правила предметной области

Название — 3–80 символов после trim. Описание — до 240 символов. Направление выбирается из фиксированного списка. Количество уроков — целое число 1–100; пройдено — целое число от 0 до общего количества. Дроби, пустые числовые поля и научная нотация не принимаются. Шаг прогресса не может превысить общее количество уроков.

Общий процент — отношение суммарного числа пройденных уроков к суммарному числу всех уроков, а не среднее процентов карточек. Удаление подтверждается; кнопка «Восстановить» в уведомлении возвращает последнюю удалённую запись без дублей, пока уведомление доступно. Уведомление автоматически закрывается примерно через 8 секунд; после перезагрузки отмена недоступна.

### Хранение и адаптивность

Из localStorage принимается только массив с корректной схемой и уникальными строковыми идентификаторами. Повреждённая запись заменяется стартовыми данными. При ошибке записи интерфейс продолжает работать в памяти и показывает предупреждение. Курсы разных репозиториев разделены ключом с `BASE_URL`.

Материалы курсов — стартовые примеры внутри исходного кода, не импортированные платные уроки. Внешних изображений, шрифтов, CDN, серверов или секретов не требуется. Локальные системные шрифты обеспечивают отображение без отдельной загрузки.

### Соответствие PDF

Инициализация и сборка Vite — корневые конфиги. Интеграция выбранной библиотеки — перечисленные компоненты и тема. Компоненты разделены по файлам, props передаются из App, адаптивность задана responsive `sx`. Unit- и E2E-проверки, README и workflow публикации включены.

## Публикация

В каждом репозитории уже есть `.github/workflows/pages.yml`. В GitHub установите **Settings → Pages → Source: GitHub Actions**, после загрузки файлов запустите workflow или сделайте push в `main`. Базовый путь берётся из метаданных Pages, поэтому любое допустимое имя репозитория не требует ручной правки конфигурации.

Полная инструкция с командами Git: [docs/PUBLISHING.md](docs/PUBLISHING.md).
