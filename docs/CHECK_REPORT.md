Для завершения проверки на машине с доступом к npm:

```bash
npm install
npm run check
npx playwright install chromium
npm run test:e2e
```

Затем включить GitHub Pages и запустить workflow. После успешной установки зафиксировать `package-lock.json` и сохранить итоговый CI-результат. Ограничение касается среды подготовки; в код не включены обходы npm, фиктивные реализации библиотек или скрытые зависимости от локальной машины.
